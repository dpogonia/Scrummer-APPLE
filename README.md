# Scrummer

Карточка ежедневного созвона.

## Что умеет приложение

Карточка показывает название встречи, число участников и длительность в минутах. В примере три встречи: Design, App Dev и Web Dev.

## Курс

Начало учебника Apple [Scrumdinger](https://developer.apple.com/tutorials/app-dev-training/getting-started-with-scrumdinger).

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/Scrummer.git
cd Scrummer
open Scrummer.xcodeproj
```

Запустите схему **Scrummer** на симуляторе iPhone.
