# Scrummer

A card for a daily meeting.

## What it does

The card shows the meeting title, how many people attend, and the length in minutes. The sample has three meetings: Design, App Dev, and Web Dev.

## Course

The start of Apple's [Scrumdinger](https://developer.apple.com/tutorials/app-dev-training/getting-started-with-scrumdinger) tutorial.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/Scrummer-APPLE.git
cd Scrummer-APPLE
open Scrummer.xcodeproj
```

Run the **Scrummer** scheme on an iPhone simulator.
